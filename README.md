# 🎮 Video Games Sales Analysis & Tableau Dashboard

## 📌 Project Overview
This project explores global video game sales across different regions, platforms, genres, and publishers. Using **Tableau**, an interactive dashboard was built to analyze historical sales trends, identify top-performing gaming platforms, and visualize regional market dominance.

---

## 📊 Key Insights & Features
- **Global Sales Distribution:** Insights into total sales broken down by North America, Europe, Japan, and Other regions.
- **Top Platforms & Genres:** Analysis of the highest-grossing gaming consoles and most popular genres (e.g., Action, Sports, Shooter).
- **Publisher Analysis:** Visualizing market share among leading video game publishers over time.
- **Interactive Dashboards:** Dynamic filtering by year, region, and platform for deep-dive analysis.

---

- **Data Preparation:** Microsoft Excel / SQL
